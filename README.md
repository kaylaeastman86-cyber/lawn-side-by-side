# Lawn Side by Side

Side-by-side comparisons of lawn and yard gear for pros and DIY homeowners. LawnSideBySide.com

- Articles: `content/articles/*.md` (see `AGENTS.md` for how to add one)
- Settings and Amazon tag: `site.config.json`
- Build: `node build.js` → `dist/` (no dependencies)
- Hosting: Vercel, auto-deploys on every push to `main`
